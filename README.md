# flygaruda-buddy
FlyGaruda AI Buddy — BiruKuning IMCC interactive concept. Simulated journeys, original GAMA / ARU / DARA mascots.

## Preview locally

Download the repository and keep all files together. From its root folder, run:

```sh
python3 -m http.server 8000
```

Open [http://localhost:8000/](http://localhost:8000/) in your browser. Stop the server with Ctrl+C. Python 3 is needed only for this local preview server.

## Files and scope

- [index.html](index.html) is the entry point.
- `index-odgzlMzV.js` and `index-C7lp4-MQ.css` are the JavaScript and stylesheet loaded by that page.
- `gama.png`, `aru.png`, `dara.png` and `favicon.svg` are the bundled visual assets.

This repository contains a built static preview; it does not include a package manifest or the original application source project. Preserve the asset filenames and relative paths when copying or serving it.

The journeys are simulated concept demonstrations, not evidence of a deployed airline service or operational booking integration.
